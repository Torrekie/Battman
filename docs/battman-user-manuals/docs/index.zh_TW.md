# Battman 1.1.0

Battman 是適用於受支援的越獄或 TrollStore iPhone、iPad 的電池與電源管理工具。它讀取裝置提供的測量值，並在環境允許時提供充電、亮度和溫控設定。可用資料和控制項取決於硬體、iOS 版本及安裝環境。

## 從這裡開始

- [安裝 Battman](installation/index.md)：選擇有根、無根或 TrollStore 套件。
- [分析](features/analytics.md)：排列十張內建卡片，查看即時讀數、充電過程和可用歷史。
- [原生外掛程式](features/plugins.md)：查看、核准和管理額外的原生卡片。
- [充電限制](controls/charging-limits.md)：啟用前了解實驗性充電限制程序的行為。
- [清除資料](preferences/wiping-data.md)：清除 Battman 設定和本機快取。

## 1.1.0 的主要變化

分析現包含十張內建卡片，涵蓋目前電池、容量觀測、電芯一致性、接電過程、電池放電、連接與充電狀態、功率讀數、電量區間停留時間、充電比較和放電節律。卡片支援不同尺寸、儲存版面配置，並可查看受支援圖形選取範圍的詳細資訊。缺少的觀測會明確顯示為空缺或無法使用。

原生外掛程式宿主與公開 SDK v1 已實作。發行矩陣另選定了單獨分發的官方 **Charge Gauge** 外掛程式和第三方 SDK 範例。本手冊描述原始碼和封裝約定；實際可下載檔案與正式簽章應以所選發行版本為準。

Battman 尚未逐一認證所有 A11 或更新裝置與 iOS 的組合。分析的即時曲線只包含前景樣本；歷史卡片讀取系統已有歷史，不會持續在背景記錄完整時間軸。目前不提供原生 macOS 應用程式。
