# Battman 1.1.0

Battman 是面向受支持的越狱或 TrollStore iPhone、iPad 的电池与电源管理工具。它读取设备提供的测量值，并在环境允许时提供充电、亮度和温控设置。可用数据和控制项取决于硬件、iOS 版本及安装环境。

## 从这里开始

- [安装 Battman](installation/index.md)：选择有根、无根或 TrollStore 软件包。
- [分析](features/analytics.md)：排列十张内置卡片，查看实时读数、充电过程和可用历史。
- [原生插件](features/plugins.md)：查看、批准和管理额外的原生卡片。
- [充电限制](controls/charging-limits.md)：启用前了解实验性充电限制进程的行为。
- [清除数据](preferences/wiping-data.md)：清除 Battman 设置和本机缓存。

## 1.1.0 的主要变化

分析现包含十张内置卡片，涵盖当前电池、容量观测、电芯一致性、接电过程、电池放电、连接与充电状态、功率读数、电量区间停留时间、充电比较和放电节律。卡片支持不同尺寸、保存布局，并可查看受支持图形选区的详情。缺少的观测会明确显示为空缺或不可用。

原生插件宿主与公开 SDK v1 已实现。发布矩阵还选定了单独分发的官方 **Charge Gauge** 插件和第三方 SDK 示例。本手册描述源码和打包约定；实际可下载文件与生产签名应以所选发布版本为准。

Battman 尚未逐一认证所有 A11 或更新设备与 iOS 的组合。分析的实时曲线只包含前台样本；历史卡片读取系统已有历史，不会连续在后台记录完整时间线。目前不提供原生 macOS 应用。
