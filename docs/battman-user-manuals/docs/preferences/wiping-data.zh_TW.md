# 清除資料

**更多 → 設定 → 清除所有 Battman 資料**會移除確認面板所列資料位置中的 Battman 偏好設定和檔案，包括儲存的分析版面配置、啟動讀數、已完成歷史快取，以及保存在這些位置的本機匯入外掛程式副本。確認前請檢查顯示的範圍。

1. 將不再需要的充電或溫控變更恢復到正常設定。
2. 開啟**更多 → 設定 → 清除所有 Battman 資料**。
3. 閱讀受影響位置並確認。成功清除後 Battman 會結束。
4. 重新開啟 Battman 並進行設定。

清除操作會先停止分析工作執行緒再刪除快取。它不會刪除系統原始 Powerlog 歷史、移除隨應用程式附帶或由套件管理器管理的外掛程式，也不會重設全域溫控設定。此外，這不是重設鑰匙圈中外掛程式回復舊版/信任計數的操作。請透過外掛程式頁面和相應安裝管道管理這些套件。移除應用程式請參閱[解除安裝](../uninstallation.md)。
