# 清除数据

**更多 → 设置 → 清除所有 Battman 数据**会移除确认面板所列数据位置中的 Battman 偏好和文件，包括保存的分析布局、启动读数、已完成历史缓存，以及保存在这些位置的本机导入插件副本。确认前请检查显示的范围。

1. 将不再需要的充电或温控改动恢复到正常设置。
2. 打开**更多 → 设置 → 清除所有 Battman 数据**。
3. 阅读受影响位置并确认。成功清除后 Battman 会退出。
4. 重新打开 Battman 并进行设置。

清除操作会先停止分析工作线程再删除缓存。它不会删除系统原始 Powerlog 历史、移除随应用附带或由软件包管理器管理的插件，也不会重置全局温控设置。此外，这不是重置钥匙串中插件回滚/信任计数的操作。请通过插件页面和相应安装渠道管理这些软件包。移除应用请参阅[卸载](../uninstallation.md)。
