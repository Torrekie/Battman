# 在 iOS 上更新

使用与当前安装一致的渠道和越狱布局。更新前阅读所选版本的说明并核对校验和。GitHub 与 Havoc 宿主是单独的构建变种，不能拿一个渠道的软件包替代另一渠道的候选包。

软件包管理器安装：刷新对应软件源并使用**升级**，或通过软件包管理器安装匹配的发布版 Debian。TrollStore 安装：按[安装说明](../installation/index.md)，明确选择并通过 TrollStore 安装替换 `Battman.tipa`。

更新宿主或插件后应重启 Battman。插件更新会再次验证；只批准准确构建不会批准其他字节内容。发布者批准仅适用于同一插件与扩展范围，不能绕过签名或回滚检查。因此，以前使用过的旧包也可能被拒绝。

TrollStore 插件变化需要正确签名的替换应用。安装前检查该 TIPA 包含哪些插件。若保存的分析卡片提供者缺失，原位置会显示**不可用**，直到恢复提供者或移除卡片。安全模式和恢复方法见[原生插件](../features/plugins.md)。
