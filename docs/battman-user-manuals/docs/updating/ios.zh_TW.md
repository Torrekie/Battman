# 在 iOS 上更新

使用與目前安裝一致的管道和越獄配置。更新前閱讀所選版本的說明並核對校驗和。GitHub 與 Havoc 宿主是單獨的建置變種，不能拿一個管道的套件替代另一管道的候選套件。

套件管理器安裝：重新整理對應軟體來源並使用**升級**，或透過套件管理器安裝相符的發行版 Debian。TrollStore 安裝：按[安裝說明](../installation/index.md)，明確選擇並透過 TrollStore 安裝替換 `Battman.tipa`。

更新宿主或外掛程式後應重新啟動 Battman。外掛程式更新會再次驗證；只核准確切組建不會核准其他位元組內容。發行者核准僅適用於同一外掛程式與擴充範圍，不能略過簽章或回復舊版檢查。因此，以前使用過的舊套件也可能遭到拒絕。

TrollStore 外掛程式變更需要正確簽署的替換應用程式。安裝前檢查該 TIPA 包含哪些外掛程式。若儲存的分析卡片提供者缺失，原位置會顯示**無法使用**，直到恢復提供者或移除卡片。安全模式和恢復方法見[原生外掛程式](../features/plugins.md)。
