# 分析

「分析」分頁以卡片顯示電池、溫度、充電、容量、循環次數與功耗資訊。所有卡片共用一個只在可見時運作的指標服務：有分析卡片顯示時 Battman 才會取樣；離開此分頁或 App 進入背景後即停止。**無法使用**表示裝置或目前環境沒有提供該項讀數，Battman 不會以估算值取代。

點一下**編輯**可加入、移除、調整大小或重新排列卡片。Battman 會保存此版面。若日後移除某個卡片提供者，原位置會保留為**無法使用**卡片，方便你辨識或移除，而不會默默遺失版面。卡片也可以提供**開啟**操作來顯示更多詳情。

內建卡片屬於 Battman 本身。原生外掛程式也可以提供卡片，但它們是在 Battman 程序內執行的程式碼，擁有與 Battman 相同的程序存取能力。核准外掛程式前請閱讀[原生外掛程式](plugins.md)。
