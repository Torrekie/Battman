# 分析

Battman 1.1.0 的「分析」標籤頁包含十張內建卡片。共用的即時指標服務只在可見時取樣；離開標籤頁或應用程式進入背景後會停止。歷史卡片另行讀取系統已有的 Powerlog 記錄，因此歷史可以早於本次應用程式階段，而短期即時曲線不會。

## 排列與查看卡片

點一下**編輯**可新增、移除、調整大小或重新排列卡片，再點一下**完成**儲存版面配置。每張卡片支援的尺寸不同。在編輯模式之外，點一下受支援的圖形點、區間、分組或充電過程可查看詳細資訊；部分卡片另提供**開啟**操作。大字體與 VoiceOver 提供同一觀測的可讀說明。如果卡片提供者被移除，已儲存位置會保留為**無法使用**卡片，直到你將其移除或恢復該提供者。

## 十張內建卡片

| 卡片 | 顯示內容 | 解讀範圍 |
| --- | --- | --- |
| 目前電池 | 電量、充電狀態、低耗電模式、電流、溫度與短期功率曲線 | 各欄位可獨立缺失；淨功率與明確標示的平均功率是不同讀數。曲線只包含前景樣本。 |
| 容量觀測 | 滿充容量、設計容量、循環觀測與可用容量歷史 | 比例需要相容的設計容量；容量變化本身不能證明更換過電池。 |
| 電芯一致性 | 主電池可用電芯電壓及其差值 | 差值需要同一次觀測中至少兩個有效通道；無歷史時會明確標示目前讀數，不補造缺失通道。 |
| 接電過程 | 一次觀測到的接電期間的電量、有正負號電流和溫度 | 插著線不等於正在充電；取樣邊界、暫停與空缺會保留。 |
| 電池放電 | 未接電時的電量下降與電池輸出 | 缺失輸出與未知重新接電時間分別說明；不會推斷哪個應用程式耗用了能量。 |
| 連接與充電狀態 | 觀測到的接電、充電、充滿、未知與衝突狀態 | 狀態切換時間受取樣邊界限制；沒有未充電原因代碼時不會猜測。 |
| 功率讀數 | 可用的輸入、電池淨功率、預算和目標 | 它們的測量位置與時間不同；預算和目標不是實際輸送功率，不能相減推導效率或損耗。 |
| 電量區間停留時間 | 按持續時間加權的電量分布，以及經過驗證的溫度分布 | 排除並說明缺失時間；不是電池損傷或健康評分。 |
| 充電比較 | 具有可信 20–80% 上升跨越的可比完整充電過程 | 排除不完整、重複、重疊及有空缺的過程；合格樣本少時可能只顯示單點或無法比較。 |
| 放電節律 | 按本地日曆時間分組的有效未接電時段電量變化率 | 接電、缺失與實測零值不同；負值保留觀測到的電量上升，不據此假定正在充電。 |

**Charge Gauge** 與 SDK 分析卡片是僅以原始碼提供的開發者範例，不屬於上述十張內建卡片。開發和測試自己的卡片請參閱[原生外掛程式](plugins.md)。

## 缺失、部分與快取資料

**無法使用**表示裝置或環境沒有提供可用測量值。歷史圖為空可能是沒有可讀的 Powerlog、欄位不受支援、樣本不足，或沒有符合該卡片條件的過程；這不等於實測零值。歷史首次讀取可能晚於目前讀數，封存記錄也可能在稍後補充涵蓋範圍。

Battman 會儲存本機啟動讀數和已完成的歷史報告，以加快再次開啟頁面的速度。快取值有明確標示；「正在顯示快取歷史；背景重新整理中」表示正在顯示較早的完整報告，同時進行更新。這裡的「背景」是分析頁面活動期間的非同步處理，不表示應用程式關閉後持續取樣。比較測量值前應查看顯示的資料時間、涵蓋範圍與空缺。

重新整理不能恢復系統從未記錄或已不再保留的資料。重新開啟分析會允許再次讀取，但不保證出現更多歷史。[清除 Battman 資料](../preferences/wiping-data.md)會移除本機快取與版面配置，不會刪除系統原始 Powerlog，也不能讓不支援的測量變得可用。

歷史卡片只使用已驗證的來源和單位，不會用示範值替代缺失的溫度、電芯或功率讀數。圖表描述觀測行為，不構成電池診斷。

原生外掛程式也可以新增卡片，但會在 Battman 程序內執行並取得相同的程序存取能力。核准前請檢查其來源與信任要求。
