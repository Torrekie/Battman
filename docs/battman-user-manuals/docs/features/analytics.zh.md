# 分析

Battman 1.1.0 的“分析”标签页包含十张内置卡片。共用的实时指标服务仅在可见时采样；离开标签页或应用进入后台后会停止。历史卡片另行读取系统已有的 Powerlog 记录，因此历史可以早于本次应用会话，而短期实时曲线不会。

## 排列与查看卡片

轻点**编辑**可添加、移除、调整大小或重新排列卡片，再轻点**完成**保存布局。每张卡片支持的尺寸不同。在编辑模式之外，轻点受支持的图形点、区间、分箱或充电过程可查看详情；部分卡片还提供**打开**操作。大字体与 VoiceOver 提供同一观测的可读说明。如果卡片提供者被移除，已保存位置会保留为**不可用**卡片，直到你将其移除或恢复该提供者。

## 十张内置卡片

| 卡片 | 显示内容 | 解读边界 |
| --- | --- | --- |
| 当前电池 | 电量、充电状态、低电量模式、电流、温度与短期功率曲线 | 各字段可独立缺失；净功率与明确标注的平均功率是不同读数。曲线只包含前台样本。 |
| 容量观测 | 满充容量、设计容量、循环观测与可用容量历史 | 比例需要兼容的设计容量；容量变化本身不能证明更换过电池。 |
| 电芯一致性 | 主电池可用电芯电压及其差值 | 差值需要同一次观测中至少两个有效通道；无历史时会明确标注当前读数，不补造缺失通道。 |
| 接电过程 | 一次观测到的接电期间的电量、有符号电流和温度 | 插着线不等于正在充电；采样边界、暂停与空缺会保留。 |
| 电池放电 | 未接电时的电量下降与电池输出 | 缺失输出与未知重新接电时间分别说明；不会推断哪个应用耗用了能量。 |
| 连接与充电状态 | 观测到的接电、充电、充满、未知与冲突状态 | 状态切换时间受采样边界限制；没有未充电原因代码时不会猜测。 |
| 功率读数 | 可用的输入、电池净功率、预算和目标 | 它们的测量位置与时间不同；预算和目标不是实际输送功率，不能相减推导效率或损耗。 |
| 电量区间停留时间 | 按持续时间加权的电量分布，以及经过验证的温度分布 | 排除并说明缺失时间；不是电池损伤或健康评分。 |
| 充电比较 | 具有可信 20–80% 上升跨越的可比完整充电过程 | 排除不完整、重复、重叠及有空缺的过程；合格样本少时可能只显示单点或无法比较。 |
| 放电节律 | 按本地日历时间分组的有效未接电时段电量变化率 | 接电、缺失与实测零值不同；负值保留观测到的电量上升，不据此假定正在充电。 |

**Charge Gauge** 是发布矩阵选定的额外官方插件，不属于上述十张内置卡片。安装方式取决于渠道及所选版本实际提供的已签名文件。请参阅[原生插件](plugins.md)。

## 缺失、部分与缓存数据

**不可用**表示设备或环境没有提供可用测量值。历史图为空可能是没有可读的 Powerlog、字段不受支持、样本不足，或没有满足该卡片条件的过程；这不等于实测零值。历史首次读取可能晚于当前读数，归档记录也可能在稍后补充覆盖范围。

Battman 会保存本机启动读数和已完成的历史报告，以加快再次打开页面的速度。缓存值有明确标示；“正在显示缓存历史；后台刷新中”表示正在显示较早的完整报告，同时进行更新。这里的“后台”是分析页面活动期间的异步处理，不表示应用关闭后持续采样。比较测量值前应查看显示的数据年龄、覆盖范围与空缺。

刷新不能恢复系统从未记录或已不再保留的数据。重新打开分析会允许再次读取，但不保证出现更多历史。[清除 Battman 数据](../preferences/wiping-data.md)会移除本机缓存与布局，不会删除系统原始 Powerlog，也不能让不支持的测量变得可用。

历史卡片只使用已验证的来源和单位，不会用演示值替代缺失的温度、电芯或功率读数。图表描述观测行为，不构成电池诊断。

原生插件也可以添加卡片，但会在 Battman 进程内运行并获得相同的进程访问能力。批准前请检查其来源与信任要求。
