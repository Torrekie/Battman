# 分析

“分析”标签页以卡片展示电池、温度、充电、容量、循环次数和功耗信息。所有卡片共用一个仅在可见时工作的指标服务：有分析卡片显示时 Battman 才会采样；离开该标签页或应用进入后台后即停止。**不可用**表示设备或当前环境没有提供该项读数，Battman 不会用估算值代替。

轻点**编辑**可添加、移除、调整大小或重新排列卡片。Battman 会保存此布局。如果以后移除了某个卡片提供者，原位置会保留为**不可用**卡片，方便你确认或移除，而不会静默丢失布局。卡片也可以提供**打开**操作以显示更多详情。

内置卡片属于 Battman 本身。原生插件也可以提供卡片，但它们是在 Battman 进程内运行的代码，拥有与 Battman 相同的进程访问能力。批准插件前请阅读[原生插件](plugins.md)。
