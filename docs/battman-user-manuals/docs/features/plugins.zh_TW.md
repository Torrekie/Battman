# 原生外掛程式

Battman 可以接收來自「檔案」或其他 App 的 `.battman` 套件文件。匯入時會先驗證並隔離套件，**不會**執行外掛程式。你可以在**更多 → 外掛程式**中查看它。

## 信任與啟用

官方外掛程式只有在發行者與其確切擴充範圍獲得 Battman 的離線簽署信任中繼資料授權後才會被接受。有效的第三方套件預設仍不受信任。Battman 會顯示外掛程式識別碼、驗證狀態、要求的擴充點，以及套件簽章中可選的作者名稱、首頁與支援電子郵件。發行者指紋和套件摘要位於**技術詳細資訊**中，並會縮短顯示；點一下即可複製完整內容以供獨立比對。作者與聯絡資訊只是套件發行者的聲明，不能建立信任。接著 Battman 才會顯示原生程式碼警告並提供兩種選擇：

- 只核准目前的確切建置；或
- 核准此發行者日後為同一外掛程式與同一擴充範圍發行的版本。

這兩種選擇都不能讓原生程式碼變得安全。外掛程式一旦載入，就能讀取或更改 Battman 可存取的任何內容、繪製任意介面、使用私有 API 或網路、使 App 當機並破壞資料。不要核准你不信任其作者或確切位元組內容的套件。簽章、摘要、架構、ABI、相依項目、撤銷、回復舊版或平台載入檢查失敗都不能被略過。

第三方載入另有一個預設關閉的總開關。安裝與啟用/停用變更會在重新啟動 Battman 後生效。越獄安裝可從 Battman 私有 App 資料目錄或系統外掛程式目錄載入已驗證套件。只使用 TrollStore 時，需要把外掛程式嵌入替換版 Battman TIPA 並重新簽署整個 App；只將原生 bundle 匯入資料目錄並不是已支援的行為。

## 復原與移除

如果 Battman 在嘗試載入第三方外掛程式後未能完成啟動，下次啟動會進入不載入第三方外掛程式的安全模式，並指出最後嘗試的建置。你也可以為下次啟動選擇**不載入第三方外掛程式啟動**，再到外掛程式畫面停用或移除確切套件。Battman 可以移除自己私有匯入的副本；隨 App 附帶或由 APT/dpkg 管理的檔案必須透過相應安裝管道更新或移除。

套件與信任驗證可以完全離線完成。比較摘要、驗證簽章、查詢本機核准/回復舊版狀態及進入安全模式都不需要網路。

## 診斷與支援

**匯出診斷** 會先顯示隱私說明，再開啟系統分享面板。純文字報告包含 Battman
版本/建置編號、產生時間、外掛程式識別碼與套件摘要、來源、信任和啟用狀態，以及有界的錯誤網域/錯誤碼。報告不包含外掛程式檔案、私密金鑰、電池測量值、裝置識別碼、在地化錯誤文字或檔案系統路徑。已安裝外掛程式清單仍可能屬於敏感資訊，因此分享前請檢查文字與接收者。

一般且不敏感的缺陷可使用公開 issue tracker。安全報告與私密診斷應遵循儲存庫的
`SECURITY.md` 政策。
